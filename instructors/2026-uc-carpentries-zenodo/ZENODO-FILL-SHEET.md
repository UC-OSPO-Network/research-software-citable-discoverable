**Description:**
Slides for a half-day, browser-based workshop on making research software citable, discoverable, and reusable, co-presented by the UC OSPO Network and UC Carpentries and hosted by UCLA. Learners fork a demo GitHub repository and add an open source license, a CITATION.cff file, a versioned release with a DOI, and better documentation and metadata. Five sets of slides, one per section: an introduction (why software citation matters, the UC OSPO Network, forking the demo repository), choosing an open source license, adding a CITATION.cff file, creating a release and minting a DOI, and improving metadata and discoverability. The slides accompany the lesson at https://ucospo.net/research-software-citable-discoverable/.
